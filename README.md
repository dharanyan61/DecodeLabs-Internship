# DecodeLabs Cloud Computing Project

## Description

This project was completed as part of the
DecodeLabs Internship Program.

The project focuses on deploying and hosting
web applications using cloud computing services.

## Technologies Used

- AWS
- HTML
- CSS
- Linux Ubuntu
- GitHub

## Project Details

- Cloud Platform: AWS
- Service: EC2
- Operating System: Ubuntu
- Web Server: Apache/Nginx

## How to Run

1. Launch the AWS EC2 instance.
2. Connect to the server using SSH.
3. Install the required web server.
4. Host the website files.
5. Access the website using the public IP address.

## Learning Outcomes

- Learned cloud server deployment.
- Learned SSH connection.
- Learned Linux commands.
- Learned web server configuration.
- Learned basic cloud infrastructure management.
